# 계산 명세

> 기능 요구사항, 계산 로직, 괘씸모드, 계산 예시. 테스트 기준값은 docs/tasks.md 참고.


## 개요

친구·가족끼리 차 한 대로 여행을 가면 운전은 대개 한 사람이 도맡습니다. 기름값과 통행료는 N분의 1로 나누지만, 서너 시간 운전한 사람의 노동은 “고마워” 한마디로 끝나는 경우가 많습니다.

이 앱은 출발할 때 “시작”, 도착해서 “완료”를 누르고, 도착 후에 넣은 기록(도착지·인원·하차·운전 교대·결제·괘씸)으로 실제 비용(유류비·통행료)과 운전 노동비를 계산해 사람별 정산 금액을 만들어 줍니다. 여기에 조수석에서 잠든 사람, 혼자 간식 먹은 사람을 반영하는 괘씸모드를 더해 정산을 대화거리로 만듭니다.

**목표**

- 운전자의 노동을 “시간 × 기준 단가” 또는 “택시였다면 들었을 기사 몫”이라는 납득 가능한 숫자로 보여준다.
- 중간 합류·하차, 운전 교대가 있어도 구간 단위로 공정하게 나눈다.
- 기름값은 실제 조회 시점 시세, 직접 주유했다면 해당 주유소 단가를 쓴다.
- 한 사람의 폰에서 입력과 계산을 끝내고, 정산 결과는 링크 하나로 공유한다.

**주요 사용자**

차를 가진 20~40대 운전자(정산 요청자)와 그 동승자. 주말 국내 여행, 명절 귀성, 캠핑·골프 모임 등.

**입력 방식**

여행 한 건은 입력 담당 한 명의 폰에서만 기록하고 계산합니다. 로그인과 회원가입은 없고, 다른 멤버는 공유받은 결과 링크만 봅니다. 출발 전에는 아무것도 묻지 않고(시작 버튼 하나), 도착 후에 도착지·인원을 받습니다. 구간·운전자·좌석은 도착 후 넣은 시각 기록에서 자동으로 만들어집니다. 나머지는 기본값으로 계산하고, 고치고 싶은 값만 결과 화면에서 고칩니다.


## 핵심 용어

| 용어          | 정의                                                                                                                  |
|---------------|-----------------------------------------------------------------------------------------------------------------------|
| 여행(Trip)    | 출발지부터 최종 도착지까지 한 번의 이동 단위. 왕복은 가는 여행·오는 여행 2개로 나누거나 한 여행 안의 구간으로 구성    |
| 구간(Segment) | 운전자·탑승자 구성이 같은 운전 단위. 사용자가 미리 정하지 않고, 하차·합류·운전 교대를 기록한 시점마다 자동으로 나뉜다 |
| 멤버          | 여행에 참여한 사람. 차주 여부, 운전 가능 여부를 가진다                                                                |
| 공통비        | 유류비 + 통행료 + 주차비. 해당 구간 탑승자 전원(운전자 포함)이 나눈다                                                 |
| 노동비        | 운전자가 받는 몫. 해당 구간의 운전자를 제외한 탑승자가 나눈다                                                         |
| 괘씸 배수     | 괘씸 점수에 따라 노동비 분담액에 곱해지는 값(1.0~2.0)                                                                 |

## 계산 로직

### 구간 자동 생성

사용자는 구간을 만들지 않습니다. 시작·완료 시각과 도착 후 넣은 기록으로 앱이 구간을 만듭니다.

    운전 시간 = 완료 시각 − 시작 시각 − 휴식 합계

검증: 도착(완료) 시각은 출발(시작) 시각보다 뒤여야 한다. 같거나 앞이면 정산하지 않고 시각을 다시 받는다.
    여행 경로 = 출발지 → 도착지 1회 조회 (거리, 예상 시간, 통행료, 택시요금)
    구간 경계 = 하차 · 합류 · 운전 교대 기록 시각
    구간 거리 = 여행 거리 × (구간 운전 시간 ÷ 전체 운전 시간)

- 하차·합류 장소를 고르면 그 지점을 경유지로 재조회해 비율 추정 대신 실제 경로 거리를 쓴다.
- 통행료는 결제 기록이 있으면 그 금액, 없으면 경로 조회값을 구간 거리 비율로 배분한다.
- 실제 운전 시간이 예상의 1.3배를 넘으면 정체인지 우회인지 앱이 판단할 수 없으므로, 결과 화면에 “경로보다 멀리 돌았나요? 거리 고치기”를 표시한다. 자동으로 거리를 늘리지 않는다.
- 좌석은 묻지 않는다. 조수석 수면 분을 넣으면 그 사람을 조수석으로 자동 지정하고, 택시모드는 좌석 변경으로 뒷자리를 표시했을 때만 적용한다.

### 유류비

차량 연비는 기본값 12km/L로 시작하고, 결과 화면에서 한 번 고치면(직접 입력 또는 차종 공인연비) 다음 여행부터 기억합니다. 공인연비에는 보정계수(도심 0.85, 고속도로 1.1)를 적용합니다.

    구간 연료량(L) = 구간 거리(km) ÷ 연비(km/L)
    구간 유류비   = 구간 연료량 × 적용 단가

적용 단가는 다음 순서로 정합니다.

- **주유 기록 없음:** 여행 조회 시점의 출발지 시·도 평균가(유종별). 조회 시각과 단가를 스냅샷으로 저장해 나중에 다시 계산해도 값이 바뀌지 않게 한다.
- **주유 기록 있음:** 주유 이후 구간은 해당 주유소 단가. 정밀 모드에서는 탱크 잔량 기준 가중평균을 쓴다.

<!-- -->

    정밀 모드 단가 = (잔량 × 기존 단가 + 주유량 × 주유 단가) ÷ (잔량 + 주유량)

### 통행료·주차비

통행료는 경로 API 값을 기본으로 하고 실제 영수증 금액으로 수정할 수 있습니다. 하이패스 할인(출퇴근·경차 등)은 수동 수정. 주차비는 발생 구간의 도착 지점에 붙여 해당 구간 탑승자가 나눕니다.

### 노동비

여행을 만들 때 산정 방식을 고릅니다.

| 방식                       | 공식                                  | 특징                                                                                              |
|----------------------------|---------------------------------------|---------------------------------------------------------------------------------------------------|
| **A. 시급형** (기본, 확정) | 운전 시간 × 기준 시급 × 난이도 계수   | 기준 시급 기본값은 해당 연도 최저시급(2026년 10,320원), 사용자가 조정 가능                        |
| **B. 택시형**              | (택시 예상요금 − 공통비) × 반영률 α   | “기사 몫”을 친구 할인해 받는 개념. α 기본 30%. 사용자가 직접 선택할 때와 괘씸 택시모드에서만 사용 |
| **C. 대리형**              | 대리운전 시세표(거리 구간별) × 반영률 | P2. 단거리·야간 모임용                                                                            |

운전 시간에는 휴게소 정차 시간을 넣지 않습니다. 기존의 개별 할증(야간·정체·연속·악천후)은 아래 난이도 지수 하나로 통합합니다.

정체와 도로 유형은 서로 겹치지 않게 나눕니다. 막혀서 느린 도로는 정체로, 원활한데도 원래 느린 도로는 도로 유형으로 셉니다. 교통 상태 코드 중 어떤 값을 정체·지체로 볼지는 카카오모빌리티 문서의 코드 정의로 확정합니다.

**계산 예시: 강릉 → 서울, 돌아오는 밤길**

20:30 출발, 휴식 없이 00:10 도착(운전 3시간 40분). 예상 2시간 40분, 비 옴, 운전자 체감 4점.

    정체    (220분 ÷ 160분 − 1) × 0.5   = +0.19
    야간    130분 ÷ 220분 × 0.3          = +0.18
    연속    100분 ÷ 220분 × 0.2          = +0.09
    도로 유형 고속도로 위주                = +0.00
    기상    비                           = +0.20
    체감    4점                          = +0.05
    난이도 계수 = 1.71

    노동비 = 3시간 40분 × 10,320원 × 1.71 = 64,706원  (난이도 없이 37,840원)

영수증에는 “난이도 1.71: 비 +0.2, 정체 +0.19, 야간 +0.18 …”처럼 큰 요소부터 사유를 표시합니다.

### 측정 한계와 보완

- **조회 시점 교통:** 경로 API의 교통 상태는 조회한 순간의 정보라 실제 주행과 다를 수 있다. 도착 후 입력하는 실제 운전 시간 비율을 주 지표로, API 값은 입력 전 예상용 보조로 쓴다.
- **공공 교통 이력은 계산이 아니라 검증에 쓴다 (2차):** 실제 운전 시간 비율은 그 사람이 그날 겪은 정체를 직접 반영하므로 도로 평균인 공공 데이터보다 정확하다. 공공 데이터는 입력한 운전 시간이 그럴듯한지 확인하는 용도로만 쓴다(어뷰징 대응 10번).
- **출발 시각 기준 예측 (2차):** 카카오모빌리티 “미래 운행 정보 길찾기”로 출발 예정 시각의 교통을 예측한다. 일 5,000건 무료이며 일일 하드 상한에 포함한다.
- **사람이 입력한 값:** 시작·완료를 누른 여행의 운전 시간은 앱이 잰 값이라 조작 여지가 작다. 지난 여행 입력(S3)으로 들어온 운전 시간과 늦게 누른 완료의 도착 시각(S2b)에는 “직접 입력” 표시를 붙인다. 결과 화면에서 직접 고친 값과 기상·체감 점수에만 “직접 입력” 표시와 원래 값을 보여준다.
- **폰 센서 (2차, 보상 미반영):** GPS 정차·출발 반복, 가속도 기반 주행 기록은 폰 안에서만 계산해 운전자 본인 기록으로만 보여준다. PWA는 화면이 켜진 동안만 측정되고 거치 위치에 따라 값이 크게 달라져 정산에는 쓰지 않는다.

### 택시비 비교

결과 화면에 “택시로 갔다면 총 얼마, 운전자 덕분에 아낀 금액 얼마”를 보여줍니다. 계산 자체에 쓰이지 않아도 운전자의 수고를 체감하게 하는 장치입니다.

    아낀 금액 = Σ 구간 택시 예상요금 − (Σ 공통비 + Σ 노동비)

### 분담 공식

구간 s에서 탑승자 수를 N(운전자 포함), 비운전 탑승자를 i라고 할 때:

    i의 공통비 분담     = 구간 공통비 ÷ N
    i의 노동비 분담     = (구간 노동비 ÷ (N − 1)) × i의 괘씸 배수
    운전자의 공통비 분담 = 구간 공통비 ÷ N   (운전자도 탑승자라서 낸다)
    운전자가 받는 금액   = Σ 비운전 탑승자의 노동비 분담

괘씸 배수는 **가산형**이 기본입니다. 괘씸한 사람이 더 낸 만큼 운전자가 더 받고, 착한 동승자의 부담은 그대로입니다. 설정에서 **재분배형**(노동비 총액은 고정, 괘씸한 사람 비중만 커짐)으로 바꿀 수 있습니다.

마지막으로 “실제로 결제한 사람”(대부분 차주)을 기준으로 멤버 간 송금 목록을 만듭니다. 금액은 원 단위 정수로 계산·표시합니다. 나눗셈에서 생기는 1원 미만은 반올림하고, 반올림으로 생긴 차이는 운전자 몫에서 흡수해 차액 합계가 항상 0이 되게 합니다.


## 괘씸모드

구간마다 멤버별 괘씸 점수를 쌓고, 점수를 배수로 바꿔 노동비 분담에 곱합니다.

    괘씸 배수 = 1.0 + 0.1 × 구간 괘씸 점수   (점수 0~10, 배수 1.0~2.0)

### 가산 항목

| 행동                            | 점수       | 비고                                                                                                                       |
|---------------------------------|------------|----------------------------------------------------------------------------------------------------------------------------|
| 조수석에서 잠                   | +1 / 20분  | 최대 +5. 도착 후 잔 시간을 분으로 넣어 환산. 조수석은 내비·졸음 방지 담당이므로 뒷자리 수면보다 무겁게                                                         |
| 뒷자리에서 잠                   | +1 / 1시간 | 최대 +2                                                                                                                    |
| 혼자 먹음 (운전자에게 안 줌)    | +1 / 회    | 과자, 음료 등                                                                                                              |
| 냄새 강한 음식을 차 안에서 먹음 | +2 / 회    | 햄버거, 오징어, 컵라면                                                                                                     |
| 부스러기·쓰레기 방치            | +2         | 하차 시 체크                                                                                                               |
| 시끄럽게 함                     | +1 / 회    | 통화, 고성, 운전자가 싫다고 한 노래 반복                                                                                   |

### 감면 항목

| 행동                                | 점수      |
|-------------------------------------|-----------|
| 운전자에게 먹여줌·음료 챙겨줌       | −1 / 회   |
| 휴게소에서 운전자 간식·커피 사줌    | −2        |
| 내비·길 안내, 졸음 방지 대화        | −1 / 30분 |
| 운전 교대 제안(실제 교대 여부 무관) | −1        |

### 택시모드 공식

    택시형 금액 = (구간 택시 예상요금 − 구간 공통비) × 30%
    택시모드 노동비 = 택시형 금액을 [시급형 × 1.5, 시급형 × 2.0] 범위로 자름
                  (여기서 시급형은 난이도 계수까지 반영한 금액)

택시 느낌은 살리되 다른 괘씸 규칙과 같은 상한(2.0배)을 지킵니다. 서울 → 원주를 둘이 갔고 동승자가 뒷자리에 앉았다면 택시형 금액은 (140,000 − 22,000) × 30% = 35,400원이지만 상한 30,960원(15,480 × 2.0)이 적용됩니다. 영수증에는 “택시였다면 기사님께 35,400원, 친구라서 30,960원”으로 표시합니다.

점수는 0 아래로 내려가지 않습니다. 감면으로 배수가 1.0보다 작아지지 않게 해서 “착한 행동으로 돈 버는” 역효과를 막습니다.

### 인정 방식

- 기록은 입력 담당 폰에서 한다. 동승자가 말로 알려주면 입력 담당이 버튼으로 남기고, 입력 담당이 운전 중이면 도착 후 몰아서 기록한다.
- 기본은 기록 그대로 반영한다. 이의가 있으면 도착 요약의 “괘씸 N건 보기”에서 체크를 해제한다(필수 단계 아님).
- 운전자는 확인 화면에서 “용서하기”로 개별 항목을 지울 수 있다.
- 잘못 누른 기록은 토스트의 “취소”(5초) 또는 타일 길게 누르기(−1)로 되돌린다.
- 결과 영수증에는 인정된 괘씸 사유가 선택한 말투로 한 줄씩 찍힌다.
