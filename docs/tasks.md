> 한 번에 한 마일스톤씩 진행한다. 각 마일스톤은 계획 → 승인 → 구현 → 테스트 → 원칙 점검 → 커밋 순서.
> 완료한 항목은 `[x]`로 바꾼다.

## 확정한 해석

기획서에서 명시가 부족한 부분을 아래처럼 해석했고, M1 시작 전에 사람이 검토해 확정했다(2026-09-16).
13~17번은 M1 구현 중 스펙에 빈칸이 있어 확정한 것이다. 바꾸려면 기준값 테스트부터 고친다.

| # | 항목 | 이 계획의 해석 |
|---|---|---|
| 1 | 금액 반올림 | 사람별 분담액은 원 단위 반올림. 반올림 차이는 해당 구간 운전자 몫에서 흡수 |
| 2 | 난이도 계수 적용 단위 | 구간별로 계산해 그 구간 노동비에 곱함 |
| 3 | 연속 운전 | 운전자별로 계산. 운전 교대나 15분 이상 휴식이면 초기화 |
| 4 | 조수석 수면 점수 | 누적 분 ÷ 20의 내림, 구간당 최대 +5 |
| 5 | 괘씸 점수 상한 | 구간·사람별 점수 0~10, 배수 = 1 + 0.1 × 점수 |
| 6 | 택시모드와 괘씸 배수 | 택시모드 구간에는 괘씸 배수를 추가로 곱하지 않음(상한 2.0 유지) |
| 7 | 체감 점수 | 5단계 1~5 → −0.1, −0.05, 0, +0.05, +0.1. 도착 요약 3단계 칩은 1·3·5로 저장 |
| 8 | 구간 거리 | 하차·합류 장소 미선택 시 여행 거리 × 구간 운전 시간 비율. 장소 선택 시 재조회 거리 |
| 9 | 통행료 배분 | 결제 기록 금액 우선, 없으면 경로 통행료를 구간 거리 비율로 배분 |
| 10 | 유가 적용 | 주유 기록 전 구간은 조회 평균가, 주유 기록 이후 구간은 주유 단가(정밀 모드 제외) |
| 11 | 최소 송금 목록 | 차액이 큰 채무자부터 큰 채권자에게 순서대로 배정하는 탐욕 방식 |
| 12 | 주유 결제와 공통비 | **확정.** 공통비는 구간 유류비 **계산값**으로 나누고, 주유 결제 금액은 결제자의 “낸 돈”으로만 반영한다. 실제 주유 금액(예: 49,500원)은 탱크에 남는 기름까지 포함해 여행 유류비와 다르므로 분담 대상으로 쓰지 않는다. 파생 규칙: 결제 항목별 “낸 돈”은 그 항목의 공통비 계산값을 넘지 않는 만큼만 정산에 반영하고, 초과분(위 예시의 49,500 − 이번 여행 유류비 몫)은 결제자 자기 부담이다. 초과분을 정산하면 동승자가 탱크에 남는 기름값까지 내게 되고 차액 합계 0이 깨진다. 영수증 계산 근거에 “주유 49,500원 중 이번 여행 몫 ○○원”으로 표시한다 |
| 13 | 구간별 예상 시간 | 전체 예상 시간을 구간 거리 비율로 배분. 하차·합류 장소를 골라 재조회한 구간은 그 조회의 예상 시간을 쓴다. 난이도 정체 요소에만 쓰인다 |
| 14 | 재분배형 공식 | i의 분담 = 구간 노동비 × (i의 배수 ÷ 비운전 탑승자 배수 합). 노동비 총액은 고정이고 괘씸한 사람 비중만 커진다. 반올림 차이는 운전자 몫에서 흡수하므로 총액이 1원까지 벌어질 수 있다 |
| 15 | 구간 통행료 우선순위 | ① 재조회한 구간 통행료 ② 통행료 결제 기록 합계를 구간 거리 비율로 배분 ③ 여행 경로 통행료를 구간 거리 비율로 배분. 해석 9를 이 순서로 읽는다 |
| 16 | 주유 단가 적용 경계 | 구간 종료 시각까지의 마지막 주유 기록 단가를 그 구간에 쓴다. 주유는 보통 구간 경계의 휴식 중에 일어난다 |
| 17 | 난이도 반올림 시점 | 요소는 원값으로 합산하고 계수만 소수 둘째 자리에서 반올림한다. 영수증에 찍는 요소별 값만 각각 반올림하므로 요소 합과 계수가 1/100 다를 수 있다 |
| 18 | 결제 기록 없는 공통비 | 결제 기록으로 덮이지 않은 공통비는 운전자(차주)가 냈다고 본다. 그렇게 하지 않으면 낸 사람이 없어 차액 합계가 0이 되지 않는다. spec-screens.md S10b 계산 근거의 "민수 40,000"이 이 경우다. `commonPaidBy: 'none'`으로 끌 수 있다 |

### 기준값 테스트 A · 강릉 여행 (spec-calc.md "계산 예시")

입력
- 멤버: 민수(차주·운전), 지현, 태호, 수빈. 시급형 10,320원, 연비 12km/L, 가산형
- 이벤트: 09:00 출발(4명) → 10:30~10:40 휴식 → 10:36 수빈 하차(장소: 원주휴게소 선택) → 10:38 주유 30L × 1,650원, 민수 결제 → 11:40 도착
- 구간 ① 서울→원주: 120km, 운전 90분, 통행료 5,000원, 유가 조회 1,700원/L, 택시 140,000원, 난이도 1.0
- 구간 ② 원주→강릉: 108km, 운전 60분, 통행료 3,150원, 유가 1,650원/L, 택시 125,000원, 난이도 1.0
- 괘씸: ① 지현 조수석 수면 60분(+3), 태호 혼자 먹음(+1) / ② 태호 시끄러움 3회(+3), 지현 기타 1회(용서함 → 0)
- 낸 돈: 이 예시는 공통비 40,000원(구간 유류비 계산값 + 통행료)을 민수가 모두 냈다고 본다. 주유 결제 금액(49,500원)을 쓰는 경우는 해석 12에 따라 기준값 테스트 E에서 따로 본다

기대값
| 항목 | 값 |
|---|---|
| ① 유류비 / 공통비 / 1인 공통비 | 17,000 / 22,000 / 5,500 |
| ② 유류비 / 공통비 / 1인 공통비 | 14,850 / 18,000 / 6,000 |
| ① 노동비 / 1인 기본 분담 | 15,480 / 5,160 |
| ② 노동비 / 1인 기본 분담 | 10,320 / 5,160 |
| 지현 보낼 돈 | 23,368 |
| 태호 보낼 돈 | 23,884 |
| 수빈 보낼 돈 | 10,660 |
| 민수 받을 돈 | 57,912 (공통비 회수 28,500 + 노동비 29,412) |
| 택시 대비 아낀 돈 | 195,588 (265,000 − 69,412) |
| 차액 합계 | 0 |

> 참고: 이 기준값은 해석 12의 결정과 무관하게 유지한다(낸 돈 = 공통비 40,000원 가정).

### 기준값 테스트 E · 주유 결제와 공통비 (해석 12)

테스트 A와 같은 입력에서 민수의 낸 돈을 주유 결제 30L × 1,650원 = 49,500원 + 통행료 8,150원으로 바꾼다.

- [x] 구간 ② 유류비는 주유 실결제액이 아니라 계산값 14,850원(9L × 1,650원)이다
- [x] 1인 공통비는 테스트 A와 같다 (① 5,500 / ② 6,000)
- [x] 주유 결제 49,500원 중 이번 여행 유류비 몫을 넘는 초과분은 민수 자기 부담이고, 동승자 4명의 보낼 돈은 테스트 A와 같다
- [x] 차액 합계는 0이다

### 기준값 테스트 B · 돌아오는 밤길 (난이도)

입력: 강릉→서울, 20:30 출발, 휴식 없이 00:10 도착(운전 220분), 예상 160분, 비, 체감 4점, 도로 유형 0
기대값: 정체 +0.19, 야간 +0.18(야간 130분), 연속 +0.09(초과 100분), 기상 +0.20, 체감 +0.05 → **계수 1.71**, 노동비 **64,706원** (난이도 없이 37,840원)

### 기준값 테스트 C · 택시모드

입력: 서울→원주 2인(민수 운전, 지현 뒷자리 표시), 택시 140,000원, 공통비 22,000원, 운전 90분, 난이도 1.0
기대값: 택시형 금액 35,400원 → 범위 [23,220, 30,960]로 잘라 **30,960원**

### 기준값 테스트 D · 규칙

- [x] 괘씸 배수는 2.0을 넘지 않는다 (점수 15 입력 → 배수 2.0)
- [x] 감면으로 점수가 0 미만이 되지 않는다

- [x] 난이도 계수는 1.0 미만, 2.0 초과가 되지 않는다
