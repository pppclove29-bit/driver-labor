사용 가이드 계산 방법 개인정보처리방침

사용 가이드

1. 출발할 때 "시작"

홈의 큰 버튼을 누르면 시각이 기록됩니다. 그대로 폰을 덮으세요. 알림도 진동도 가지 않고, 백그라운드에서 도는 것도 없습니다.

2. 도착해서 "완료"

같은 자리의 버튼이 완료로 바뀌어 있습니다. 누르면 운전 시간이 정해집니다.

완료를 깜빡하고 한참 뒤에 열었다면 "언제 도착했어요?"를 한 번 묻습니다. 시간을 자동으로 잘라내지 않습니다.

3. 도착지와 인원 넣기

어디에 도착했는지 검색해서 고르면 거리·통행료·택시요금·지역 평균 유가를 조회합니다. 목록에서 고르지 않고 이름만 적어도 정산은 됩니다.

인원은 +, − 로 맞춥니다. 이름은 결과 화면에서 바꿉니다.

4. 넣고 싶은 것만 더

  • 괘씸·감면: 조수석에서 잔 시간, 혼자 먹기, 간식 사주기 같은 기록. 구간·사람당 2회까지.
  • 타임라인: 중간에 내린 사람, 운전 교대, 휴식 시간, 기름값·통행료를 누가 냈는지.
  • 고치기: 거리·통행료·연비·시급·유가를 결과를 보면서 바꿉니다.

아무것도 넣지 않아도 정산은 끝납니다.

5. 결과 공유

결과 링크를 보내면 친구는 앱 없이 금액을 봅니다. 값을 고치면 링크를 다시 만들어 보내세요.
