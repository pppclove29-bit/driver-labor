# @dl/site

소개·사용 가이드·계산 방법·개인정보처리방침 정적 페이지. Worker의 `/`로 서빙한다.

- 빌드 단계가 없다. HTML과 CSS 파일 그대로 `dist-assets/`로 복사된다.
- 외부 스크립트·폰트·분석 도구·광고를 넣지 않는다(결과 보기 페이지와 같은 원칙).
- 주소: `/`(소개), `/guide`, `/calc`, `/privacy`. Cloudflare 정적 자산이 `.html` 없이도 찾아 준다.
- 스토어 등록정보에 넣을 개인정보처리방침 URL이 `/privacy`다. 실제 도메인은 배포 때 정한다.
